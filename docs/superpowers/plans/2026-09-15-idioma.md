# El idioma — plan 3 de 4 del lanzamiento público

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** el árbol que se publica habla inglés entero —prosa, código, mensajes y documentos— y un test lo vigila para que no vuelva a hablar español.

**Architecture:** una cremallera. La tarea 1 escribe `tests/test_public_tree.py`, que detecta español sobre el árbol público y lleva una lista `PENDING` de siete entradas: los archivos que todavía no se tradujeron. Cada tarea traduce lo suyo y borra su línea. Cuando la lista queda vacía el test deja de perdonar nada, y ese es el criterio de terminado: no "lo leí y se ve bien", sino un gate que corre en los tres sistemas del CI.

El orden va de adentro hacia afuera. Primero los nombres propios —que no es traducción sino privacidad, y cuanto antes salga mejor—, después `src/`, que es quien emite los mensajes, después `tests/`, que los cita, y al final los documentos, que describen lo que los dos primeros ya dicen en inglés. Traducir el README antes que el CLI obligaría a traducirlo dos veces.

**Tech Stack:** Python 3.11+, pytest, `re` de la stdlib. Delegación de bulto mecánico a reasonix (DeepSeek V4) según §8 del diseño; prosa de cara al usuario con la skill `solace-wren`.

**Spec:** `docs/superpowers/specs/2026-09-12-lanzamiento-publico-design.md` — §8 entero, más §9.7/§9.8 (historia de origen sin identificar a nadie) y §6.3 (lo que cambie el contrato sale en el CHANGELOG bajo *breaks*).

## Global Constraints

- **Inglés estadounidense.** Un solo registro en todo el árbol. Ni británico ni mezcla.
- **`docs/superpowers/**` y `.superpowers/**` quedan FUERA.** Se purgan enteros en §9.5. **Ninguna tarea los traduce, ni los edita para que un chequeo calle, ni los mete en un sweep.** En el plan 2c un grep con el alcance abierto terminó editando la spec para silenciarse; eso es lo prohibido. Lo que sí ocurre, y es distinto: **quien orquesta el plan enmienda este documento** cuando dictamina algo que lo contradice —un defecto del propio plan, un glosario incompleto, una regla mal enunciada—. Eso es autoría deliberada, deja rastro en un commit con su razón, y es lo contrario de un sweep borrando evidencia. Cada enmienda de esas está en el historial de esta rama.
- **El glosario del apéndice A es vinculante.** El mismo término español se traduce igual en las siete tareas. Un término que falte se añade al apéndice en la misma tarea que lo necesita.
- **La superficie pública no se traduce.** Todo nombre que aparezca en un `__all__`, las claves del JSON, los códigos de `warnings` (`empty_transcript`, `language_mismatch`, `no_speech_regions`, `gain_limited`), los de `AsrError` (`unsupported_option`, `model_integrity`, `backend_failed`, `out_of_memory`, `cancelled`, `insufficient_resources`) y los valores de `QualityReason`, `AudioViewName` y `Stage` ya están en inglés y se quedan exactamente como están. Cambiarlos rompe el contrato sin que nadie lo haya pedido.
- **Los identificadores locales y privados sí se traducen** — variables, ayudantes con guion bajo, constantes de módulo. Hay 13 en español en `src/` (`hay_pico`, `con_error`, `idioma`, `voz`, `NOMBRE`, `salida`, `sondeo`, `con_wer`, `nombre`, `nombres`, `modelos`, `voces`) y 23 en `tests/` (`_voz_sintetica`, `_zip_con_exe`, `MODULOS_CON_ALL`, `ruta`, `trozo`, `trozos`, `muestras`, `ganancia_db`, `largo_pero_hablado`, `solo_wcpp`, `con_pausa`, y más), y **ninguno aparece en un `__all__`** — comprobado con el tokenizer de Python el 2026-09-15. Una variable local no tiene contrato que romper, y dejarlas haría imposible cerrar la cremallera: el detector busca a propósito dentro de los `snake_case`, que es lo único que le permite ver el español de los nombres de test. La suite verde es la prueba de que el renombre no rompió nada.
- **Una excepción, declarada:** `Cap = Literal["honrado", "degradado", "rechazado"]` (`src/speechtotext/asr/base.py:13`) sí se traduce a `Literal["honored", "degraded", "rejected"]`, porque es el único tipo público con valores en español. Es un *break* de la API y sale en el CHANGELOG como tal (tarea 7).
- **Un valor histórico citado es dato, no prosa.** Cuando un archivo cita una grafía vieja *porque era la grafía vieja*, traducirla destruye la referencia en vez de traducirla. Ya pasó tres veces en este plan: el patrón `src/static/texto.txt` de `.gitignore`, que guardaba un archivo real que §9.5 manda purgar; el fixture `{"caso": "conversacion_en_vivo", …}` de `tests/test_benchmark.py:375`, que es el esquema **viejo** que la migración de `read_table()` tiene que reconocer —traducirlo deja el test de migración probando nada—; y la entrada de `CHANGELOG.md` que cita lo que una versión pasada realmente emitía. La prueba para distinguirlos: si al cambiar la palabra el texto pasa a afirmar algo falso **sobre algo que ya salió** o deja de casar con algo real, es dato y se queda. Si describe comportamiento que todavía no se ha publicado, no es historia: es borrador, y se traduce **y se corrige**. Por eso `CHANGELOG.md:100` —que cita el viejo `"whisper.cpp (PATH, sin pin)"` bajo el encabezado *Sin publicar*, no bajo una versión— es prosa de la tarea 7: si esa sección se estampa con un número de versión tal como está, el CHANGELOG publicado describirá mal la versión que documenta.
- **El español que es dato se declara, no se esconde.** `tests/test_public_tree.py` reconoce un marcador de línea, `# spanish-is-data: <por qué>`, que saca esa línea de los tres chequeos de idioma —nunca del de nombres: un nombre real jamás es dato—. Es por línea y no por archivo, y el motivo es obligatorio: un perdón a nivel de archivo ciega el archivo entero, y uno sin motivo deja de leerse a la primera semana. Lo que el marcador **no** es: una forma de callar español que simplemente no se ha traducido. La prueba es si traducirlo rompería algo, no si traducirlo molesta. Dos tests del propio archivo comprueban que el marcador sigue siendo por línea y que uno sin motivo no exime nada. Hoy lo usan tres líneas: el fixture del esquema viejo de `bench.json` y los dos tests de `normalize()`/`search()`, donde las tildes son la entrada de una función que quita tildes.
- **Un literal que se compara contra otro archivo pertenece a la tarea que traduce ese archivo.** Las cadenas de `pytest.raises(match=...)` y los `assert "..." in result.stdout` viajan con los mensajes de `src/` (tarea 3), no con la prosa de `tests/` (tarea 5). Las sondas de `test_api_contract.py` contra `docs/api.md` viajan con `api.md` (tarea 7). Traducir el literal antes que su fuente deja el gate rojo.
- **Gate después de cada tarea:** `.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider`. Base al empezar: **480 passed, 1 skipped**. El número no baja nunca. Si una tarea renombra tests, el total se conserva exacto.
- **Los mensajes de commit de esta rama en adelante van en inglés**, cuerpo incluido. El repo se publica en inglés; escribir ahora en español es fabricarle trabajo a la tabla del plan 4.
- **Ningún nombre propio real de persona** en el árbol público: ni en tests, ni en fixtures, ni en documentos. Desde la tarea 2 el test lo vigila sin lista de perdón.

Crea `tests/test_public_tree.py` con exactamente esto:

```python
"""The public tree speaks English. This file is the ratchet.

It does not grade English or judge style. It finds Spanish that nobody translated,
using three cheap signals:

  1. Letters English does not write: n-tilde, inverted marks, accented vowels.
     One is enough to flag the line.
  2. Spanish function words, at a threshold of TWO distinct words per file. The
     threshold is the point: `con`, `los` and `solo` are English words too, and a
     one-hit rule would grow an exception list until nobody reads it. No ten-word
     Spanish sentence contains only one function word.
  3. The project's own Spanish vocabulary -- the left column of the plan's
     glossary. `trozo`, `hueco`, `hablante` and the rest are not English in any
     reading, so one hit is enough.

What this cannot see, said plainly: a three-word comment with no accent in it.
`# sube el pin` trips nothing. The complement is the sampled read that section 8
of the design asks for, not more regex.

PENDING lists the files nobody has translated yet. Each task of the plan deletes
its line. When the list empties, the test stops forgiving -- and that, not
anyone's opinion, is what "done" means here.

Deliberately out of scope: `docs/superpowers/` and `.superpowers/`. Section 9.5
strips both from the published tree, so translating them is wasted work -- and a
sweep that includes them ends up editing the design document to silence a grep,
which is exactly what happened during plan 2c.
"""
import re
from pathlib import Path

import pytest

ROOT = Path(__file__).resolve().parents[1]
SELF = Path(__file__).relative_to(ROOT).as_posix()

# What ships. `docs/superpowers/` is not here and never will be.
WATCHED = (
    "src",
    "tests",
    "scripts",
    ".github",
    "docs/api.md",
    "docs/README.md",
    "docs/design.md",
    "README.md",
    "CHANGELOG.md",
    "pyproject.toml",
    ".gitignore",
)

# Still untranslated. One line per task; they come off in order.
PENDING = (
    "src/",                          # task 4
    "tests/",                        # task 5
    "README.md",                     # task 6
    "docs/api.md",                   # task 7
    "CHANGELOG.md",                  # task 7
    "scripts/benchmark_chart.py",    # task 7
    "docs/README.md",                # task 8
)

# Terms English writes with an accent. Not leftover Spanish.
ALLOWED = ("Bézier",)

ACCENTS = re.compile("[ñÑ¿¡áéíóúüÁÉÍÓÚÜ]")

# Spanish function words that are not English words. `en` and `es` are left out on
# purpose: they are language codes and appear everywhere (`language="es"`). So are
# `todo` and friends -- `# TODO:` would trip them.
#
# `del` stays in despite being a Python keyword: it is the densest single signal in
# this repo's Spanish (68 occurrences in comments) against one file that uses `del`
# as a statement. If a fully translated file ever fails this check with `del` among
# the words listed, that is the reason -- and it still needs a second, real hit to
# fail at all.
#
# The boundary is a lookaround, not `\b`, because `\b` treats `_` as a word
# character: `test_mide_voz_ruido` hides every word in it from `\b`, and test names
# are 414 of the strings this file exists to find.
FUNCTION_WORDS = re.compile(
    r"(?<![A-Za-z0-9])(que|para|del|las|los|una|uno|este|esta|esto|estos|estas"
    r"|como|cuando|donde|porque|pero|aunque|desde|hasta|entre|sobre|cada|nada"
    r"|algo|hay|tiene|tienen|puede|pueden|debe|deben|dice|dicen|hace|hacen"
    r"|mismo|misma|otro|otra|sino|antes|siempre|nunca|menos|ahora|luego"
    r"|entonces|ser|estar|tener|hacer|por|nos|les|sus|muy|con|solo)"
    r"(?![A-Za-z0-9])",
    re.IGNORECASE,
)

# The glossary's left column: this project's Spanish nouns and verbs. One hit is
# enough -- none of these is an English word. `motor` and `vista` belong to the
# glossary but are left out here on purpose: English writes both.
GLOSSARY = re.compile(
    r"(?<![A-Za-z0-9])(trozo|trozos|trocear|troceado|troceada|costura|costuras"
    r"|hueco|huecos|sondeo|sondear|ruta|rutas|huella|huellas|senal|senales"
    r"|hablante|hablantes|muestra|muestras|reloj|medido|medida|medidas|apagon"
    r"|apagones|cuantizacion|ganancia|recorte|recortar|pista|pistas|honrado"
    r"|degradado|rechazado|aparato|archivo|archivos|modelo|modelos|salida"
    r"|salidas|entrada|entradas|prueba|pruebas|palabra|palabras|mensaje"
    r"|mensajes|nombre|nombres|tiempo|silencio|voz|voces|calidad|idioma"
    r"|texto|textos|habla|transcripcion|segmento|segmentos|tabla|tablas"
    r"|caso|casos|bajo|sola)"
    r"(?![A-Za-z0-9])",
    re.IGNORECASE,
)


def _files():
    """Every text file under WATCHED, skipping PENDING and this file."""
    for entry in WATCHED:
        root = ROOT / entry
        if not root.exists():
            continue
        candidates = sorted(root.rglob("*")) if root.is_dir() else [root]
        for path in candidates:
            if not path.is_file():
                continue
            # The suffix filter guards directory walks only. An entry that names
            # a file names it on purpose, and `.gitignore` has no suffix at all:
            # Path(".gitignore").suffix is "".
            if root.is_dir() and path.suffix not in (".py", ".md", ".toml", ".yml"):
                continue
            rel = path.relative_to(ROOT).as_posix()
            if rel == SELF or any(rel == p or rel.startswith(p) for p in PENDING):
                continue
            yield rel


def _read(rel: str) -> str:
    text = (ROOT / rel).read_text(encoding="utf-8")
    for allowed in ALLOWED:
        text = text.replace(allowed, "")
    return text


FILES = sorted(_files())


@pytest.mark.parametrize("rel", FILES)
def test_no_spanish_letters(rel):
    hits = [
        f"{rel}:{n}: {line.strip()[:90]}"
        for n, line in enumerate(_read(rel).splitlines(), 1)
        if ACCENTS.search(line)
    ]
    assert not hits, "untranslated Spanish:\n" + "\n".join(hits)


@pytest.mark.parametrize("rel", FILES)
def test_no_spanish_function_words(rel):
    found = {m.group(0).lower() for m in FUNCTION_WORDS.finditer(_read(rel))}
    assert len(found) < 2, (
        f"{rel} uses {len(found)} distinct Spanish function words "
        f"({', '.join(sorted(found))}): that is Spanish prose, not a false positive"
    )


@pytest.mark.parametrize("rel", FILES)
def test_no_spanish_vocabulary(rel):
    found = {m.group(0).lower() for m in GLOSSARY.finditer(_read(rel))}
    assert not found, f"{rel} still uses the Spanish glossary: {', '.join(sorted(found))}"


def test_pending_only_names_things_that_exist():
    """A PENDING entry pointing at nothing is a task that forgot to delete its
    line: the file left the watch list and nobody noticed."""
    orphans = [p for p in PENDING if not (ROOT / p).exists()]
    assert not orphans, f"PENDING names paths that do not exist: {orphans}"
```
