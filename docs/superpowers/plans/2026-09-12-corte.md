# El corte — plan de implementación (1 de 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sacar de speechtotext el aparato privado (`evaluation/`, `security/`, `models/`, `confidence/`, `statistics.py`) y dejar la librería compilando, con suite verde y contrato honesto, sin que ningún módulo que se queda dependa de lo que se fue.

**Architecture:** Primero se publica `v0.5.1` como ancla (el consumidor copia de ahí lo que absorbe). Después se rompen las tres únicas costuras que unen lo que se queda con lo que se va — `audio/fingerprint.py` (proveniencia exige `VerifiedModelArtifact`), `asr/base.py` (Protocols verificados) y `asr/faster_whisper.py` (constructor con artefacto) — y `TranscriptionResult` pierde sus campos de calibración. Solo entonces se borran los paquetes. Este plan NO unifica los dos backends ni toca el CLI: eso es el plan 2 (núcleo).

**Tech Stack:** Python ≥ 3.11, pytest, dataclasses frozen, faster-whisper (solo por `model_factory` en tests).

**Spec:** `docs/superpowers/specs/2026-09-12-lanzamiento-publico-design.md` — secciones §2 (decisiones), §3 (frontera), §9.2 y §11.

## Global Constraints

- Ningún módulo de `src/speechtotext/{asr,audio,core,cli,speakers}` importa de `speechtotext.{evaluation,security,models,confidence,statistics}` al terminar (spec §3).
- La suite corre sin GPU, sin red y sin modelos: los backends se construyen con `model_factory` falso (spec §7).
- `audio/` se queda entero; solo cambia el tipo que `PipelineProvenance` acepta en `models=` (spec §3).
- Los payloads de proveniencia (`model_fingerprints`) no cambian de forma: las huellas ya calculadas siguen siendo válidas (spec §3, costo declarado).
- Prosa y código en español en este plan: la traducción es el plan 3 (spec §8). Se aprovecha cada archivo tocado para quitar nombres de proyectos privados de fixtures (`"Aurelius"`, `"Tachira"`), pero no se buscan más allá.
- Versión tras el corte: `0.6.0.dev0` en `pyproject.toml` y `speechtotext.__version__` (spec §9.3: primera pública `0.6.0`).
- Gate local: `.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider` verde antes de cada commit. Si la suite revienta con un stack de C, es la trampa conocida de Windows: reintentar, no es tu código.

```python
class FasterWhisperBackend:
    backend_id = "faster-whisper"

    def __init__(
        self,
        model: str | Path,
        config: FasterWhisperConfig | None = None,
        *,
        model_version: str = "unpinned",
        model_factory: Callable | None = None,
        clock: Callable[[], float] = time.perf_counter,
    ) -> None:
        # Un nombre lo resuelve faster-whisper (cache de HF Hub); una ruta es un
        # directorio CTranslate2 y se carga solo local. Este backend no verifica pesos:
        # quien lo haga por manifiesto lo envuelve, pasa la ruta verificada y su
        # revision como model_version.
        if isinstance(model, Path):
            self._model_path: Path | None = model
            self._model_id = model.name
        elif isinstance(model, str):
            if not model.strip():
                raise ValueError("model no puede estar vacio")
            self._model_path = None
            self._model_id = model
        else:
            raise TypeError("model debe ser un nombre (str) o una ruta (Path)")
        if not isinstance(model_version, str) or not model_version.strip():
            raise ValueError("model_version no puede estar vacio")
        self.config = config if config is not None else FasterWhisperConfig()
        self._model_version = model_version
        self._model_factory = model_factory
        self._clock = clock
        self._model = None

    @property
    def config_fingerprint(self) -> str:
        return self.config.fingerprint

    @property
    def model_id(self) -> str:
        return self._model_id

    @property
    def model_version(self) -> str:
        return self._model_version

    def warm(self) -> None:
        if self._model is not None:
            return
        factory = self._model_factory
        if factory is None:
            from faster_whisper import WhisperModel

            factory = WhisperModel
        self._model = factory(
            str(self._model_path) if self._model_path is not None else self._model_id,
            device=self.config.device,
            compute_type=self.config.compute_type,
            cpu_threads=self.config.cpu_threads,
            num_workers=self.config.num_workers,
            local_files_only=self._model_path is not None,
        )
```
